<p>Este repositório foi criado para entregar o exercício final do módulo de Fundamentos de HTTP, onde aprendi a sobre requisições, respostas, métodos e etc.</p>

<p>A Proposta era de utilizar o <a href="https://crudcrud.com">CrudCrud</a>. para gerar um banco de dados temporário para que pudessemos enviar e receber informações via API, permitindo o cadastro de novos usuários e a exibição de usuários já existentes, assim como a possibilidade de excluir um usuário caso fosse necessário, tudo isso pelo front-end. </p>
